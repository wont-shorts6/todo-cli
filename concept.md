# Хранение задач

## Краткое определение

Хранение задач — это механизм, благодаря которому `todo-cli` сохраняет
список задач между запусками программы. Все задачи лежат в одном файле
`tasks.json` в папке проекта.

## Назначение

Механизм нужен, чтобы задачи не пропадали после закрытия терминала.
Без него каждая новая сессия начиналась бы с пустого списка. Хранение
в обычном файле делает данные прозрачными: их можно прочитать, скопировать
или добавить в систему контроля версий вместе с кодом.

## Принцип работы

Файл `tasks.json` — это текстовый файл в формате JSON. Внутри него
находится массив объектов; каждый объект описывает одну задачу и содержит
три поля:

- `id` — уникальный номер задачи, по нему задачу можно отличить от других;
- `text` — текст задачи, который ввёл пользователь;
- `done` — признак выполнения: `false`, пока задача активна, и `true`,
  когда она отмечена выполненной.

При добавлении задачи утилита формирует новый объект, присваивает ему
следующий свободный `id` и дописывает его в массив. При отметке задачи
выполненной значение поля `done` у нужного объекта меняется на `true`.
При выводе списка утилита читает файл, разбирает JSON и показывает задачи
в порядке их `id`.

Если файл `tasks.json` отсутствует, утилита считает, что задач ещё нет,
и работает с пустым списком. Файл создаётся при первом изменении данных.
Формат JSON выбран потому, что он читается и человеком, и программой,
а также легко версионируется в Git: изменения видны построчно.
