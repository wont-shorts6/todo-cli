# Установка

## Что нужно
- Node.js версии 18 или новее.
- Любой терминал (командная строка).

## Как установить
1. Скачайте проект: `git clone https://github.com/wont_shorts6/todo-cli.git`
2. Перейдите в папку: `cd todo-cli`
3. Установите зависимости: `npm install`

## Как проверить, что всё работает
Выполните:
todo list

text
Если появилось пустое сообщение «Задач нет» — установка прошла успешно.

## Если что-то пошло не так
- Ошибка `command not found: todo` — проверьте, что установка прошла до конца.
- Ошибка `node: not found` — не установлен Node.js, вернитесь к разделу «Что нужно».
