# Установка

## Что нужно
- Node.js версии 18 или новее.
- Любой терминал (командная строка).

## Как установить
1. Скачайте проект: `git clone https://github.com/ВАШ_ЛОГИН/todo-cli.git`
2. Перейдите в папку: `cd todo-cli`
3. Установите зависимости: `npm install`
