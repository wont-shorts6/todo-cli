# Справочник команд

| Команда | Что делает | Пример |
|---|---|---|
| `add` | Добавляет задачу | `todo add "Текст задачи"` |
| `list` | Показывает все задачи | `todo list` |
| `done` | Отмечает задачу выполненной | `todo done 1` |

## Пояснения
- Номер задачи можно узнать командой `list`.
- Текст задачи пишется в кавычках, если содержит пробелы.
- Задачи хранятся в файле `tasks.json` в папке проекта.
