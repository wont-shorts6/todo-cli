# Как пользоваться

Программа `todo` работает из терминала. Вот три главных сценария.

## Добавить задачу
Напишите:
todo add "Купить хлеб"

text
Программа ответит: «Задача добавлена».

## Посмотреть список задач
Напишите:
todo list

text
Вы увидите пронумерованный список. Номер нужен, чтобы отмечать задачи выполненными.

## Отметить задачу выполненной
Напишите `todo done` и номер задачи. Например, чтобы закрыть первую:
todo done 1

text
