# Инвентаризация документации

## 1. Что за проект
Учебный проект `todo-cli` — консольная утилита для ведения списка задач.
Назначение: показать полный цикл работы технического писателя — от структуры
репозитория до справочника команд.
Основные возможности: добавление задач, просмотр списка, отметка выполненных.

## 2. Кто пользуется
- Разработчики — читают README и reference.
- Конечные пользователи — читают how-to и installation.
- Администраторы — настраивают окружение по installation.

## 3. Что есть

| Документ | Где лежит | Состояние |
|---|---|---|
| README.md | корень репозитория | актуален, есть ссылки на docs |
| installation.md | docs/ | актуален, без скриншотов |
| how-to.md | docs/ | актуален, три сценария |
| reference.md | docs/ | актуален, таблица команд |

## 4. Чего не хватает
- Нет документа `troubleshooting.md` (частые ошибки пользователей).
- В `installation.md` нет скриншотов — сложно для новичков.
- Нет единого оглавления со ссылками на все документы.
- Нет примера файла `tasks.json` — непонятен формат хранения.

## 5. Открытые вопросы
- Неясно, кто отвечает за обновление `reference.md` при добавлении команд.
- Нужно уточнить, для кого `how-to.md`: для пользователей или разработчиков.
- Стоит ли выносить примеры кода в отдельный файл `examples.md`.
