# todo-cli

Консольная утилита для ведения списка задач прямо из терминала.
Задачи хранятся в обычном файле `tasks.json` рядом с проектом.

## Зачем это нужно

- Не нужно открывать браузер или тяжёлое приложение — всё в терминале.
- Задачи хранятся локально, без интернета и аккаунтов.
- Список можно версионировать вместе с кодом через Git.

## Требования

- Node.js версии 18 или новее.
- Любой терминал: Bash, Zsh, PowerShell.

## Быстрый старт

1. Склонируйте репозиторий:
git clone https://github.com/wont_shorts6/todo-cli.git

2. Перейдите в папку проекта:
cd todo-cli

3. Установите зависимости:
npm install

4. Добавьте первую задачу:
todo add "Купить хлеб"

5. Посмотрите список:
todo list


Если после `todo list` появилась ваша задача — всё работает.
