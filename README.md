# todo-cli

Консольная утилита для ведения списка задач. Работает из терминала, задачи хранит в файле `tasks.json`.

## Быстрый старт
- [Установка](docs/installation.md)
- [Как пользоваться](docs/how-to.md)
- [Справочник команд](docs/reference.md)

## Возможности
- добавление задач;
- просмотр списка;
- отметка выполненных задач.
